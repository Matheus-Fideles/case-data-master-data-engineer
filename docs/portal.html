Decisões de Arquitetura

🏗️ Data Mesh (ADR-0009)

Código organizado em apps/{domínio}/ — cada domínio dono de suas fontes, jobs e schemas.

🔐 LGPD (ADR-0006)

PII mascarado com SHA-256+salt na transição Bronze→Silver. Salt em k8s Secret, nunca em código.

⚡ Gold em Delta (ADR-0011)

Gold grava em MinIO (Delta Lake) em vez de Postgres JDBC. Trino + HMS serve os dados via SQL.

🔄 Idempotência

Toda escrita usa replaceWhere Delta Lake — re-execuções são seguras sem duplicatas.

🏃 Lambda Architecture

Batch via Airflow/Spark + Streaming via Kafka/Spark Structured Streaming → mesma camada Gold.

🧪 Template Method

SilverJob e FatoLoader definem fluxo fixo; subclasses implementam apenas o que varia.
